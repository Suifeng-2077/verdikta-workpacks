Cross-surface

One position, six views

A risk position taken on the Risk board appears here with the same id, so the explorer doubles as the audit trail.

Search

Query by structure

Filtering is by market structure first, not by product. Users arrive with a question, not with an engine preference.

Agents

Readable to machines

Every row exposes the same fields the trading agents use, so a human and a bot see an identical book.

Design note. The explorer deliberately has no hero illustration and no editorial cards at the top — density is the feature. Everything above the table is a filter or a number you would want before scanning 1,284 markets.
